Refresh

  • refreshMessages(_:)

    Reloads Inbox messages from each operational producer (Marketing Cloud Engagement, Mobile App Messaging, or both).

    Manual refresh is limited to one request per minute. A call made before that interval elapses, while Inbox is disabled, or while the module is not operational completes with false and MessageProducer/inboxFeature.

    During server-side throttling a producer may answer 429 - Too Many Requests. That failure is delivered through completion and is not sent to InboxResponseDelegate.

    The completion is invoked once for each expected producer. Success and failure from a producer are delivered on the main queue. A refused refresh stays on the calling thread.

    Declaration

    Swift

    public func refreshMessages(_ completion: ((Bool, MessageProducer) -> Void)?)

    Parameters

    completion

    Optional one-shot callback. Pass nil to refresh without completion callbacks. Registering a completion does not replace an InboxResponseDelegate.

Feature Toggle

  • setInboxEnabled(_:)

    Enables or disables Inbox processing for this app.

    Disabling Inbox cancels a refresh that is still waiting for producers. It does not delete messages already downloaded. While Inbox is disabled, reads return empty results, mutations return false, analytics no-op, and refreshMessages completes with false. No-op if the module is not operational.

    Declaration

    Swift
