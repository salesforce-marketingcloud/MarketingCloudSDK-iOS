InboxMessage

@objc(SFMCSdkInboxMessage)
public protocol InboxMessage

Public protocol representing an inbox message from the Marketing Cloud. Consumers receive instances of this protocol via InboxFeature methods. Every property is read-only: an inbox message is an immutable snapshot of what the SDK received. Optional properties are nil when the backend did not supply a value.

Identifiers

  • messageId

    Unique identifier for the message. Maps to messageId from the server payload.

    Declaration

    Swift

    var messageId: String { get }
  • messageType

    The kind of inbox message.

    Declaration

    Swift

    var messageType: InboxMessageType { get }
  • source

    The SDK module that originated this inbox message. See ModuleName for possible values.

    Declaration

    Swift

    var source: String? { get }
  • audienceType

    Audience string. Known values: device, user. Unknown values are surfaced as-is. Missing or empty is device.

    Declaration

    Swift

    var audienceType: String { get }

Content

  • subject

    Subject line of the inbox message. Displayed as the primary title in inbox list views.

    Declaration

    Declaration

    Swift

  • message

    Body text of the inbox message.

    Declaration

    Swift

    var message: InboxText? { get }
  • action

    Message-level call to action. Track a tap with InboxMessageInteraction(type: .cta, id: nil). value is the clicked text.

    Declaration

    Swift

    var action: InboxAction { get }
  • custom

    Custom string payload attached to the message.

    Declaration

    Swift

    var custom: String? { get }
  • customKeys

    Custom key/value pairs attached to the message, flattened into a single dictionary. The backend delivers these as an array of {key, value} objects; the inbox module flattens them at parse time so consumers receive a straightforward [String: Any]. On duplicate keys the last pair wins; pairs missing a String key are dropped.

    Declaration

    Swift

    var customKeys: [String : Any]? { get }
  • sound

    Sound identifier associated with the message.

    Declaration

    Swift

    var sound: String? { get }
  • media

    Message’s media asset, if any.

    Declaration

    Swift

    var media: InboxMedia? { get }
  • buttons

    Buttons on this message, in payload order. nil when the message has none. Track a tap with InboxMessageInteraction(type: .button, id: button.id).

    Declaration

    Swift

    var buttons: [InboxButton]? { get }
  • notificationMessage

    Raw notification payload backing the message, if delivered via push.

    Declaration

    Swift

    var notificationMessage: [String : Any]? { get }
