Inbox Message Details

  • InboxMessage

    Public protocol representing an inbox message from the Marketing Cloud. Consumers receive instances of this protocol via InboxFeature methods. Every property is read-only: an inbox message is an immutable snapshot of what the SDK received. Optional properties are nil when the backend did not supply a value.

  • InboxInteractionType

    Classifies the engagement object the user tapped on an inbox message.

    Distinct from InboxActionType, which describes what a tap does (WEB_URL, APP_URL, and so on). This type only says which object was tapped.

    • .cta: the message-level call to action. Pass id: nil.
    • .button: a button on the message. id must be that button’s InboxButton.id.
